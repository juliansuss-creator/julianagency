Julian Suss Ads Tool

An internal tool built by Julian Suss to automate Google Ads campaign optimization across multiple client accounts. This tool uses the Google Ads API to perform budget pacing, negative keyword management, keyword pausing, ROAS adjustment, and Performance Max monitoring automatically.

About This Application

Julian Suss Ads Tool is an internal application developed by Julian Suss, an independent Google Ads consultant managing campaigns for e-commerce and B2B clients in Argentina and Mexico through MCC account 602-402-1674.

The tool is used exclusively for internal campaign management purposes. It is not distributed, resold, or offered as a service to third parties. All Google Ads accounts accessed by this tool belong to clients who have explicitly authorized management access.

The application connects to the Google Ads API using OAuth 2.0 authorization to read account data and apply optimizations automatically on a scheduled basis.

What This Tool Does

The Julian Suss Ads Tool automates the following tasks across all managed client accounts:

  • Budget Pacing — Reads monthly budget caps and redistributes daily budgets proportionally to avoid overspending without pausing campaigns.
  • Negative Keyword Management — Reads Search Terms reports and adds exact-match negative keywords for terms with zero conversions above a minimum impression threshold. Covers both Search and Performance Max campaigns.
  • Keyword Pausing — Automatically pauses keywords with excessive spend and no conversions, high CPC relative to account average, high CPA relative to account average, or zero search volume. New keywords are excluded.
  • ROAS Adjustment — Reads actual conversion value data from the last 14 days and adjusts Target ROAS settings for Maximize Conversion Value campaigns.
  • Performance Max Monitoring — Monitors Performance Max campaigns for low ROAS, underperforming placements, and audience signal performance. Sends automated alerts when thresholds are breached.
  • RSA Generation — Uses the Keyword Plan Idea Service and existing RSA asset performance data to generate optimized responsive search ad copy for new campaigns.
