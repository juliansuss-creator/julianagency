Internal Tool

Google Ads automation platform

I am developing an internal tool that connects to the Google Ads API to automate recurring optimization tasks across all client accounts under my MCC. The tool is for my exclusive internal use — it is not distributed, resold, or offered as a SaaS product.

Automated modules

  • Budget Pacing — redistributes daily budgets proportionally to match monthly spend targets without pausing campaigns.
  • Negative Keywords — reads Search Terms reports, identifies zero-conversion terms above impression thresholds, and adds exact-match negatives at campaign level for both Search and Performance Max.
  • Keyword Pausing — pauses keywords by spend, CPC relative to account average, CPA relative to account average, or zero search volume. New keywords are excluded automatically.
  • ROAS Adjustment — reads actual conversion value data from the last 14 days and adjusts tROAS targets for Maximize Conversion Value campaigns.
  • Performance Max Monitoring — alerts on low-ROAS asset groups, identifies underperforming placements, and adjusts campaign budgets based on day-of-week ROAS patterns.
  • RSA Builder — generates responsive search ad copy from product data using the Keyword Plan Idea Service and existing asset performance signals.
