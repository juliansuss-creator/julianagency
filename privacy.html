Privacy Policy

Last updated: September 29, 2026

Application Name

Google Ads Automation Tool, developed and operated by Julian Suss (julian.suss@gmail.com).

Overview

This Privacy Policy describes how Google Ads Automation Tool ("the Tool", "the Application") collects, uses, and protects data accessed through the Google Ads API. The Tool is an internal application used exclusively by Julian Suss to manage Google Ads campaigns on behalf of clients who have explicitly authorized access to their accounts via OAuth 2.0.

Data Collected

The Tool accesses the following types of data through the Google Ads API:

  • Campaign performance metrics: impressions, clicks, conversions, cost, conversion value, ROAS
  • Search term reports from Search and Performance Max campaigns
  • Keyword-level performance data: CPC, CPA, conversion rates, impression share
  • Campaign budget amounts and bidding strategy settings (including Target ROAS values)
  • Responsive Search Ad (RSA) asset text and performance labels (BEST, GOOD, LOW)
  • Product feed performance data from Shopping and Performance Max campaigns
  • Placement and audience performance data from Performance Max campaigns

Purpose of Data Use

All data accessed through the Google Ads API is used exclusively for automating campaign optimization tasks, specifically:

  • Redistributing daily campaign budgets to match monthly spend targets
  • Identifying search terms with zero conversions and adding them as negative keywords
  • Pausing keywords that exceed spend, CPC, or CPA thresholds relative to account averages
  • Adjusting Target ROAS settings based on real 14-day conversion value performance
  • Monitoring Performance Max campaign asset groups and sending performance alerts
  • Generating keyword and RSA copy recommendations for new campaign launches

Data Storage and Retention

The Tool does not store Google Ads account data in any external database, cloud service, or third-party platform. All data is retrieved from the Google Ads API, processed in real time to perform the optimization task, and is not retained after each execution. No logs containing account data are kept beyond the immediate session.

Data Sharing

Data accessed through the Google Ads API is never shared with third parties, sold, licensed, or used for any purpose other than managing the authorized Google Ads accounts listed under MCC account 602-402-1674. The Tool is for internal use only and is not distributed, resold, or made available to any other party.

Authorization and Access

The Tool accesses Google Ads accounts exclusively through OAuth 2.0 authorization granted by the account owner. Only accounts for which explicit authorization has been granted are accessed. Authorization can be revoked at any time through the Google account security settings.

User Data

The Tool does not collect, access, or process any personal data of end users, customers, or website visitors. Only Google Ads campaign performance data is accessed, and this data does not include personally identifiable information of any individual.

Security

All API credentials, OAuth tokens, and developer tokens are stored securely on local infrastructure controlled exclusively by Julian Suss. Credentials are never shared, published, or exposed publicly. Access to the Tool is limited to the developer (Julian Suss) only.

Google API Services User Data Policy

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is not used for advertising purposes, is not transferred to third parties, and is not used to build user profiles.
