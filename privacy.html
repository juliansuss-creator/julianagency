Privacy Policy

Last updated: September 29, 2026

Overview

This privacy policy describes how Julian Suss ("I", "me") collects, uses, and protects data accessed through the Google Ads API as part of an internal campaign automation tool ("the Tool"). The Tool is used exclusively for managing Google Ads campaigns on behalf of clients who have explicitly authorized access to their accounts.

Data Collected

The Tool accesses the following data through the Google Ads API:

  • Campaign performance metrics (impressions, clicks, conversions, cost, ROAS)
  • Search term reports from Search and Performance Max campaigns
  • Keyword performance data (CPC, CPA, conversion rates)
  • Campaign budget and bidding strategy settings
  • Responsive Search Ad (RSA) asset performance labels
  • Product feed performance data from Shopping campaigns

How Data Is Used

All data accessed through the Google Ads API is used exclusively for the following purposes:

  • Automating budget adjustments to optimize monthly spend pacing
  • Identifying and adding negative keywords to reduce irrelevant traffic
  • Pausing underperforming keywords based on spend, CPC, and CPA thresholds
  • Adjusting Target ROAS settings based on real conversion performance
  • Monitoring Performance Max campaign asset groups and placements
  • Generating keyword and RSA copy recommendations for new campaigns

Data Storage

The Tool does not store Google Ads account data in any external database or third-party service. All data is processed in real time and is not retained after each execution. No personal data of end users or customers is accessed or stored.

Data Sharing

Data accessed through the Google Ads API is never shared with third parties, sold, or used for any purpose other than managing the authorized Google Ads accounts. The Tool is for internal use only and is not distributed or resold.

Access and Authorization

The Tool accesses Google Ads accounts only through OAuth 2.0 authorization. All accounts are managed through a centralized MCC account (ID: 602-402-1674). Only accounts for which explicit client authorization has been granted are accessed.

Security

All API credentials and OAuth tokens are stored securely on local infrastructure and are never exposed publicly. Access is limited to the account owner (Julian Suss) only.

Google API Services

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
